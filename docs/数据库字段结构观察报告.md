# 数据库字段结构观察报告

## 一、数据库模型字段总览

### 1. products（产品表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| product_code | String(50) | 产品编码，唯一 |
| product_name | String(100) | 产品名称 |
| industry | String(20) | 行业：化工/能源/农副/有色 |
| category | String(50) | 品类 |
| unit | String(20) | 单位，默认"元/吨" |
| source | String(50) | 数据源 |
| source_url | String(500) | 数据源URL |
| is_active | Boolean | 是否启用 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

### 2. price_records（价格记录表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| product_id | Integer | 外键，关联products |
| price | Float | 价格 |
| currency | String(10) | 币种，默认CNY |
| unit | String(20) | 单位 |
| price_original | String(100) | 原始报价文本 |
| price_category | String(20) | 价格类别：现货/期货 |
| price_type | String(20) | 价格类型 |
| trend | String(10) | 趋势：涨/跌/平 |
| change_percent | Float | 变化百分比 |
| source | String(50) | 数据源 |
| region | String(50) | 地区/产地 |
| supplier | String(100) | 供应商 |
| brand | String(100) | 品牌 |
| specification | String(200) | 规格 |
| extra_data | JSON | 行业差异化字段 |
| record_date | Date | 记录日期 |
| created_at | DateTime | 创建时间 |

### 3. categories（分类表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| name | String(50) | 分类名称 |
| parent_id | Integer | 外键，指向自身（一级/二级结构） |
| sort_order | Integer | 排序 |
| created_at | DateTime | 创建时间 |

### 4. product_categories（产品-分类关联表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| product_id | Integer | 外键，关联products |
| category_id | Integer | 外键，关联categories |
| created_at | DateTime | 创建时间 |

### 5. alert_configs（预警配置表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| product_id | Integer | 外键，关联products |
| alert_type | String(20) | 预警类型：threshold/change_rate/trend |
| threshold_value | Float | 阈值 |
| change_percent | Float | 变化百分比 |
| is_active | Boolean | 是否启用 |
| created_at | DateTime | 创建时间 |

### 6. alert_records（预警记录表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| alert_config_id | Integer | 外键，关联alert_configs |
| product_id | Integer | 外键，关联products |
| alert_message | String(500) | 预警消息 |
| triggered_price | Float | 触发时价格 |
| triggered_at | DateTime | 触发时间 |
| is_read | Boolean | 是否已读 |

### 7. scraper_logs（爬虫日志表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| scraper_name | String(50) | 爬虫名称 |
| status | String(20) | 状态：running/success/failed |
| items_scraped | Integer | 抓取数量 |
| error_message | String(500) | 错误信息 |
| started_at | DateTime | 开始时间 |
| completed_at | DateTime | 完成时间 |

### 8. operation_logs（操作日志表）
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | Integer | 主键 |
| timestamp | DateTime | 时间戳 |
| level | String(10) | 级别：INFO/WARNING/ERROR |
| module | String(20) | 模块 |
| action | String(20) | 操作类型 |
| details | String(1000) | 详情JSON |
| result | String(20) | 结果 |
| operator | String(50) | 操作人 |

## 二、后端接收字段（Pydantic模型）

### 产品管理（products.py）

**ProductCreate（创建产品）**
- `product_code`: str（必填）
- `product_name`: str（必填）
- `industry`: Optional[str]，默认"化工"
- `category`: Optional[str]，默认"化工"
- `unit`: Optional[str]，默认"元/吨"
- `source`: Optional[str]
- `source_url`: Optional[str]
- `category_ids`: Optional[List[int]]

**ProductUpdate（更新产品）**
- `product_name`: Optional[str]
- `industry`: Optional[str]
- `category`: Optional[str]
- `unit`: Optional[str]
- `source`: Optional[str]
- `source_url`: Optional[str]
- `is_active`: Optional[bool]
- `category_ids`: Optional[List[int]]

**ProductResponse（产品响应）**
- `id`: int
- `product_code`: str
- `product_name`: str
- `industry`: Optional[str]
- `category`: Optional[str]
- `unit`: Optional[str]
- `source`: Optional[str]
- `is_active`: bool

**BatchProductItem（批量导入）**
- `product_name`: str（必填）
- `industry`: str（必填）
- `category`: Optional[str]，默认"化工"
- `unit`: Optional[str]，默认"元/吨"
- `source`: Optional[str]，默认"shengyishe"
- `source_url`: Optional[str]

### 价格数据（prices.py）

**PriceRecordCreate（创建价格记录）**
- `product_id`: int（必填）
- `price`: float（必填）
- `currency`: Optional[str]，默认"CNY"

- `specification`: Optional[str]

**/prices/latest 响应字段**

- `latest_date`: str（yyyy/mm/dd格式）

## 三、前端接收字段（API调用）

### price.js API 模块

**getPrices(params)** → GET /api/v1/prices
- 接收字段：id, product_id, product_name, product_code, price, trend, change_percent, source, region, supplier, brand, specification, record_date

**getLatestPrices(params)** → GET /api/v1/prices/latest
- 返回：{total: int, data: Array}
- data字段：product_id, product_name, product_code, industry, latest_date, price, min_price, max_price, change_percent, trend, source, specification, brand, region, supplier, price_type, unit

**getDashboardRanking(params)** → GET /api/v1/prices/dashboard/ranking
- 返回：{rising: Array, falling: Array}
- 每项：product_id, product_name, latest_price, change_percent, avg_price

**getDashboardIndicatorCards(params)** → GET /api/v1/prices/dashboard/indicator-cards
- 返回：{total_products, avg_price, avg_change_percent, items}

**getDashboardHistoryCompare(...)** → GET /api/v1/prices/dashboard/history/compare
- 返回：{dates: Array, series: Array[{name, data}]}

### productApi

**getProducts(params)** → GET /api/v1/products
- 返回：Array<{id, product_code, product_name, industry, category, unit, source, is_active}>

**createProduct(data)** → POST /api/v1/products
- 发送：product_code, product_name, industry, category, unit, source, source_url, category_ids

**updateProduct(id, data)** → PUT /api/v1/products/{id}
- 发送：product_name, industry, category, unit, source, source_url, is_active, category_ids

**batchImportProducts(data)** → POST /api/v1/products/batch
- 发送：{products: Array<{product_name, industry, category, unit, source, source_url}>}

### alertApi

**getAlertConfigs(params)** → GET /api/v1/alerts/configs
- 返回：Array<{id, product_id, product_name, industry, category_id, alert_type, threshold_value, change_percent, is_active, created_at}>

**createAlertConfig(data)** → POST /api/v1/alerts/configs
- 发送：product_id, alert_type, threshold_value, change_percent, is_active

**getAlertRecords(params)** → GET /api/v1/alerts
- 返回：Array<{id, alert_config_id, product_id, product_name, alert_type, alert_message, triggered_price, triggered_at, is_read}>

### categoryApi

**getCategories()** → GET /api/v1/categories
- 返回：Array<{id, name, parent_id, sort_order, subcategories: Array}>

**getLevelOneCategories()** → GET /api/v1/categories/level-one
- 返回：Array<{id, name, parent_id, sort_order, created_at}>

**getLevelTwoCategories(parentId)** → GET /api/v1/categories/level-two/{parentId}
- 返回：Array<{id, name, parent_id, sort_order, created_at}>

**setProductCategories(productId, categoryIds)** → POST /api/v1/categories/product/{productId}
- 发送：{category_ids: Array<int>}

## 四、字段格式说明

### 日期格式
- **数据库**：Date类型（yyyy-mm-dd）或DateTime类型
- **后端响应（price_records）**：yyyy/mm/dd格式（如"2026/05/20"）
- **后端接收（PriceRecordCreate）**：YYYY-MM-DD格式（如"2026-05-20"）

### 趋势字段（trend）
- 枚举值：涨 / 跌 / 平

### 行业字段（industry）
- 枚举值：化工 / 能源 / 农副 / 有色

### 预警类型（alert_type）
- 枚举值：threshold / change_rate / trend
